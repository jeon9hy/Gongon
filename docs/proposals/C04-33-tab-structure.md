# 상단 탭 정보 구조 재기획안 (C04-33, 2026-10-21, 개발자 확인 전)

상태: **제안**. 개발자 확인 뒤 결정(D-번호)으로 옮기고 구현한다. 확인 전에는 화면을 바꾸지 않는다.
PDF 판(화면 예시 포함): `docs/proposals/C04-33-tab-structure.pdf`(개발자 메일에 링크로 보냄).

## 1. 지금 구조의 문제
| 지금 | 문제 |
| --- | --- |
| 주 메뉴: 홈 · 작업 일정(달력·공온 판정·판정 내역) · 내 현장 · 대화 (D-084) | 제품의 중심 흐름(D-055) `변경 → 조치 → 완료 보고 → 검증`이 주 메뉴에 없다 |
| 변경·내 조치는 이름 메뉴 → 내 정보 → ‘내 업무’ 카드 | 두 번 눌러야 하고, 내 정보는 계정 화면이라 업무를 찾으러 가지 않는다 |
| 참여 업체·담당자는 내 현장 → 현장 고르기 → `참여 업체·담당자` 버튼 | 업체 명부는 원청 담당자가 매일 쓰는 것(전화·배정)인데 설정 화면 안쪽에 있다. 업종을 고를 곳도 없다 |
| 내 현장은 주소·좌표·작업 기간 편집이 대부분 | 한 번 정하면 거의 안 바꾸는 설정이 주 메뉴 한 칸을 차지한다. 이미 현장 `···` 메뉴(D-083)에 수정·삭제가 있다 |
| 현장 고르기가 화면마다 다르다(홈 탭·판정 드롭다운·일정 드롭다운) | 지금 어느 현장을 보는지 화면을 옮길 때마다 다시 확인해야 한다 |

## 2. 제안 (추천안 A)
주 메뉴 5개: **홈 · 일정 · 변경·조치 · 업체 · 대화**. 내 현장은 주 메뉴에서 빼고 머리줄의 **현장 고르기**로 옮긴다.

| 탭 | 하위 메뉴 | 들어가는 기존 화면 | 바뀌는 점 |
| --- | --- | --- | --- |
| 홈 | 없음 | `/` | 오늘 보드 위에 ‘내가 처리할 조치 n건 · 검증 대기 n건’ 한 줄 추가 |
| 일정 | 달력 · 공온 판정 · 판정 내역 | `/schedule` `/dashboard` `/judgments` | 이름만 ‘작업 일정’ → ‘일정’(휴대폰 아래 탭 폭) |
| 변경·조치 | 변경 건 · 내 조치 · 검증 대기(검증자만) | `/changes` `/actions` | 내 정보에서 꺼내 주 메뉴로. 처음 화면은 열린 변경 건 |
| 업체 | 참여 업체 · 담당자 | `/sites/{id}/members` | 업체 카드에 업종(맡은 공종)·오늘 작업 수·열린 조치 수. 업종은 작업 고르기와 같은 업종 모달로 고름(다음 작업 2) |
| 대화 | 없음 | `/chat` | 그대로 |

- **현장 고르기**: 머리줄 로고 오른쪽에 현재 현장 이름 칩. 누르면 참여 현장 목록 + `현장 추가` + `현장 설정`(지금의 내 현장 편집 화면). 고른 현장은 모든 탭에 같이 적용(지금의 `site_id` 주소 값 유지, 화면 사이 이동에서 이어 붙임). ‘전체 현장’은 홈·일정·판정 내역에서만 고를 수 있다.
- 머리줄의 파란 `현장 추가` 버튼은 현장 고르기 안으로 옮긴다(현장 추가는 드물고, 주 동작 자리를 차지한다).
- **휴대폰**: 위 탭 대신 아래 탭 막대 5칸(아이콘 + 두 글자 이름: 홈·일정·조치·업체·대화). 하위 메뉴는 지금처럼 화면 위 알약.
- **역할별**(D-057 권한은 그대로, 보이는 탭만 다름):
  - 조정자(원청 공사·공무): 5개 모두.
  - 담당자(협력업체 현장대리인·반장, 원청 안전·품질): 홈 · 일정 · 변경·조치(내 조치가 첫 화면) · 업체(보기 전용, 연락처는 자기 업체와 원청만) · 대화.
  - 열람자(감리·CM): 홈 · 일정 · 변경·조치(보기) · 대화. 업체 탭은 숨김(연락처 제외 원칙).
- 내 정보는 이름 메뉴에 남고 계정·휴대폰·참여 현장만 보인다(‘내 업무’ 카드는 탭으로 옮겨 빠짐).

## 3. 다른 안
| 안 | 내용 | 장점 | 단점 |
| --- | --- | --- | --- |
| A(추천) | 위 5탭 + 현장 고르기 | 중심 흐름이 주 메뉴에 나옴, 업체 명부 한 번에 | 탭 하나 늘어남, 내 현장 위치가 바뀌어 익숙해질 시간 필요 |
| B | 4탭 유지: 홈 · 일정 · 변경·조치 · 대화, 업체는 ‘현장’ 하위 메뉴(현장 정보 · 업체 · 담당자) | 탭 수 그대로 | 업체 명부가 여전히 한 단계 안쪽 |
| C | 6탭: A + 내 현장 유지 | 지금 위치 그대로 | 휴대폰 아래 탭 6칸은 좁다(390px에서 칸당 65px) |

## 4. 구현 순서 (확인 뒤, 하위 작업마다 검증·커밋)
1. N1 주 메뉴 바꾸기: 탭 5개·하위 메뉴, 내 정보의 ‘내 업무’ 카드 제거. 주소·권한·DB 변경 없음.
2. N2 업체 탭: 참여 업체·담당자 화면을 탭으로 옮기고 업체 카드에 업종·오늘 작업·열린 조치. 업종 고르기는 ‘참여 업체 업종’ 작업(DB 변경, 결정 따로)과 함께.
3. N3 변경·조치 탭: 변경 건·내 조치·검증 대기 하위 메뉴, 홈의 한 줄 요약.
4. N4 현장 고르기 칩: 머리줄, 현장 추가·현장 설정 이동, 화면 사이 `site_id` 이어 붙임.
5. N5 휴대폰 아래 탭 막대(390px 실제 조작 확인).
6. 역할별 탭 숨김과 직접 주소 접근 시험(숨긴 탭도 서버 권한 검사는 그대로).

## 5. 개발자 확인이 필요한 것
1. 안 A / B / C 중 무엇으로 갈지.
2. 탭 이름: ‘변경·조치’(추천) / ‘변경’ / ‘업무’.
3. 협력업체 담당자에게 업체 탭을 보일지(추천: 보기 전용으로 보임).
4. 머리줄 `현장 추가` 버튼을 현장 고르기 안으로 옮겨도 되는지.
