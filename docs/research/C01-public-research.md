# C01 공개 자료 조사 결과 (2026-10-16)

범위: 공식 공개 문서·공개 제품 설명·공개 연구로 확인한 사실, 그로부터 정한 설계 가정, 확인하지 못한 항목, C02에 넘길 합성 시나리오. 실제 건설사 내부 자료·인터뷰는 사용하지 않았다(D-056). 이 문서는 시장성·현장 효과의 검증 결과가 아니다.

표기: **확인** = 출처 원문(또는 공식 도움말)에서 직접 읽음. **2차** = 검색 요약·2차 해설로만 확인, `[원문 대조 필요]`. 모든 확인일 2026-10-16.

## 3. 설계 가정 (C02 계약에 반영, 고객 확인 전 시연용)

- A1 역할: 프로젝트 참여 업체마다 `원청`/`협력업체` 구분, 사용자 역할은 `조정자`(변경 제안·확정·검증 가능), `담당자`(자기 업체 조치 처리), `열람자`. 실제 전결 구조는 미확인 → 시연용 기본값으로 표시.
- A2 확정 권한: 원청 조정자만 변경을 확정한다. 협력업체는 제안·막힘 보고만. (P8의 도급인 조정 역할과 정합)
- A3 자기 검증: 기본 금지(수행자 ≠ 검증자). 프로젝트 설정으로 허용할 수 있게 하되 실제 행위자 기록. 고객 정책 미확인.
- A4 기한: 조치 처리 기한만 둔다. 미정 허용(null + 사유). 공급사 취소 마감은 별도 항목으로도 첫 범위에 넣지 않음.
- A5 근거: 첫 범위는 텍스트 근거(처리 내용·상대·참조 번호·처리 시각). 파일 첨부는 저장 정책 확정 후(C06 이후 검토).
- A6 프로젝트 = 기존 Site(기획 12장). 별도 Project 테이블 없음.
- A7 사유 분류: 11개 요인(현재 product.md §1)(P7과 대응), 복수 선택.
