# 작업 목록 (상태의 유일한 기준)

상태: `todo → doing → review → done`. 막히면 `blocked`와 해결 조건. 계획 작성은 기능 완료가 아니다.
여기에는 열린 작업만 둔다. 끝난 행·예전 S작업·분해 메모는 `plan-archive.md`(필요할 때만). 새 작업은 product.md 절·결정 번호를 적는다.

## 방향 (D-055·D-056)

- 고객: 대형 건설사 한 프로젝트의 원청과 참여 협력업체. 중심: **공사 변경 뒤 필요한 조치를 연결하고 실제 완료 근거까지 확인**. 기상 판정은 변경 근거 중 하나다.
- 주 사용자: 원청 현장 공사·공무 담당자(D-066). 보조: 원청 안전·품질, 소장, 협력업체 현장대리인·반장, 감리. 작업자는 현장 게시 화면(D-067).
- 실제 내부 자료·인터뷰·고객 확보를 구현 선행 조건으로 두지 않는다. 공개 자료와 `[가상]` 합성 사례로 비상업 시연을 만들고, 가상 자료를 실제 응답·현장 검증·사업성 증거로 표시하지 않는다. 실제 현장 효과는 C08.
- 다음 순서: C13 나머지(앱 화면 b~f·PC 홈 현황판) → 공유·키 결정(`launch-checklist.md`) → C13-3 배포 → C07 나머지(발송 대기) → 문자 인증 → 운영자 화면(`admin-spec.md`).
