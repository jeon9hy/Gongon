### C01 완료 증거와 조사 양식 (공개 자료로 진행)

- 조사 기록: 공식 공개 자료·사례·서식의 URL·확인일·확인 사실·적용 범위·미확인 사항. 이를 바탕으로 단일 작업 시간 변경의 합성 시나리오와 필요한 조치를 제안한다. 실제 고객·기한·손실·연락 내역을 확보했다고 표시하지 않는다.
- 이후 고객에게 확인할 것: 실제 전결·검증 역할·양식·PMIS 번호·민감 자료·도입/구매 경로. 지금은 확인 항목으로 보존하고 제안 역할·양식을 시연용으로 명시해 구현한다.
- 같은 사례를 콘업·Procore Action Plans·Touchplan 및 현행 방식과 비교한다. 공개 문서에서 못 찾았다는 이유로 기능 부재를 확정하지 않는다. 실제 시연을 못 했으면 그 비교는 미검증이다.
- C01 완료: 출처와 비교표·설계 가정·미확인 목록·첫 시나리오가 정리되면 공개 조사 작업을 완료할 수 있다. 현장 반복 문제·입력 절감·지불 의사가 검증됐다는 뜻은 아니다. 실제 효과 측정은 C08로 분리한다.

### 실제 사례 없이 진행하는 범위

공식 공개 자료 조사·명시한 합성 사례·구현 계약을 거쳐 C03~C07의 비상업 시연 구현을 진행한다. 내부 자료·인터뷰·고객 확보를 기다리며 멈추지 않는다. 가상 자료를 실제 API 응답·현장 검증·사업성 증거로 표시하지 않는다. 실제 계정·비용·기준 원문은 지어내지 않고 막히지 않은 구현을 계속한다.
