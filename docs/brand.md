# 브랜드 가이드: 공온

화면 문구·알림 문구·서비스 용어를 만들 때 이 문서를 따른다. 판정 원칙(`AGENTS.md`, 총정리 §1)과 부딪히면 판정 원칙이 우선한다.

## 1. 이름
- 서비스 이름: **공온** (공사 + ON). "공사가 켜지는 날을 미리 본다"는 뜻.
- 코드·저장소 식별자: `gongon` (패키지 이름, 앱 제목 등 영문이 필요한 곳)
- 상표·도메인 사용 가능 여부: `[미확인]` — 외부 공개 전 개발자가 KIPRIS·도메인으로 확인하고 `docs/decisions.md`에 기록

## 2. 서비스 용어

| 용어 | 뜻 | 상태 |
| --- | --- | --- |
| 공온 알림 | 매일 17시에 받는 내일 판정 알림 | 사용 |
| 공온 판정 | 공종별 기상 판정 기능과 그 결과 | 사용 |
| 내일 공사 ON? | 대시보드·알림의 질문형 제목. 답은 아래 판정 4단계로 보여준다 | 사용 |
| 공온지수 | 점수형 지표(예: "공온지수 82") | **보류 — 정의 전 사용 금지** (§4) |

### 판정 4단계는 바꾸지 않는다
`진행 / 확인 필요 / 중지 검토 / 판정 불가`는 데이터 계약·화면·알림에서 이 이름 그대로 쓴다.
브랜드 용어로 대체하거나 별칭을 만들지 않는다. 하나의 결과에 두 가지 이름이 생기면 이해와 기록이 엇갈리기 때문이다.

- "공사 ON"을 판정 결과 라벨(예: `진행` 대신 "오늘 공사 ON")로 쓰지 않는다. `진행`도 현장 안전을 보장하지 않는데(총정리 §1), "ON"은 작업 허가처럼 읽힌다.
- "ON"은 질문형 제목(`내일 공사 ON?`)과 브랜드 문구에서만 쓴다.

## 3. 문구 원칙
- 알림·상세 화면에는 항상 판단 보조 문구를 넣는다: "최종 판단은 현장 책임자가 합니다."
- 쓰지 않는 표현: "안전합니다", "보장", "알아서 정해드려요", "자동으로 일정 변경"처럼 판정을 확정·보증하는 말
- 슬로건 후보: "내일 공사 ON?", "공사 켜기 전에, 공온"
- 알림 첫 줄 형식 예: `[공온] 내일(10/5) ○○현장 · 철골 13:00–17:00 중지 검토 (강우)`
- 카카오톡 발송은 사업자 등록 후 제공한다(D-015). 그 전에는 알림 화면·설정에 "카카오톡 발송은 사업자 등록 후 제공 · 지금은 웹에서 확인"으로 표시하고, "발송됨"처럼 실제 발송한 것으로 읽히는 문구를 쓰지 않는다.

## 4. 공온지수 — 보류 중인 결정
총정리에 없는 기능이므로 개발자가 범위에 추가하기로 정하기 전에는 구현하지 않고, 화면에 점수를 표시하지 않는다.
채택한다면 다음 조건을 만족하는 정의를 먼저 `docs/decisions.md`에 기록하고 별도 작업 ID로 진행한다.
- 규칙 기반·결정적: 같은 입력·같은 기준 버전 → 같은 점수. LLM 사용 없음
- 설명 가능: 점수의 각 구성 요소가 근거 조항·예보값으로 설명됨
- 판정과 모순되지 않음: `중지 검토`인데 높은 점수가 나오는 일이 없어야 함. 점수가 판정을 대신하지 않음
- 누락·비교 불가 데이터는 점수를 내지 않음(임의 기본값 금지)
- 계산식에 버전을 붙여 판정 내역과 함께 저장

## 5. 시각 요소 (D-038, 2026-10-08 개발자 레퍼런스)
- 기준: 개발자가 첨부한 Pilo Black / Electric Green 팔레트와 흰 바탕 모바일 앱 이미지. D-037의 남색·청회색·판정별 넓은 컬러 면을 대체한다.
- 흰 바탕, 검정 요약 영역, 회색 목록으로 큰 구역을 나눈다. 라임은 주 행동 버튼·선택한 메뉴/날짜·브랜드 토글에 한정한다. 밝은 라임을 작은 글자색으로 쓰지 않는다.
- 판정 4단계 이름은 그대로다. 진행은 옅은 회색 배지, 확인 필요는 검정 실선 테두리, 중지 검토는 검정 배지와 흰 글자·강한 경계, 판정 불가는 회색 글자와 점선 경계로 구분한다. 홈의 검정 요약에서는 흰 라벨과 수치를 쓰고 중지 검토에 밑줄을 더한다. 색상만으로 의미를 전달하지 않는다.
- 정렬·밀도: 제목과 패널 본문의 안쪽 시작선 20px(모바일 16px), 설명과 링크 분리, 시간 라벨과 값 묶음 유지. 입력/버튼 6px·내부 묶음 8px·패널 10px 모서리. 이전 피드백에 따라 레퍼런스의 큰 곡률을 그대로 복제하지 않는다.
- Pretendard 직접 제공. 제목 28~32px/500, 소제목 18px/600, 본문 14px/400. 전환 0.18초, 동작 줄이기 설정 존중.
