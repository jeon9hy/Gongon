## 실제 브라우저

- Codex 앱 내 Chromium, 개발 DB 현장 38. setup의 Alembic 적용 후 uvicorn 실행 방식 사용. 기존 8000 서버와 별도로 QA 서버 `127.0.0.1:8001`을 실행해 로그 확인.
- 폭·높이: 데스크톱 1440×900, 휴대폰 390×844. 세로 스크롤바를 뺀 문서 폭은 각각 1425·375.
- 홈·일정·공온 판정·판정 내역·판정 상세·변경 목록·현장·참여자·가이드·내 정보: 두 폭에서 모두 `scrollWidth == clientWidth`, 정상 제목·내용 표시. 주간 표의 내부 스크롤은 유지.
- 홈: 오늘 시간 순서·단계, 내일 5항목 집계, 7일 지수·점수 없음 사유, 새로 점검 버튼 실제 실행과 확인 시각 갱신 확인.
- 일정: 공종 점→해당 작업 상세, 추가(직접 입력 0930→09:30), 날짜·월 선택, 계획 수정 펼침, 삭제 확인, 모달 Esc·바깥 누름 확인.
- 추가로 390×420의 짧은 화면에서 시간 목록 높이가 178.2px로 줄고 y=233.8~412 안에 배치되는 것 확인. 실제 화면 키보드를 연 검증은 아니다.
- 변경: QA 작업 223·변경 건 3을 생성. 초안→영향 검토→확정(v1), 재변경(v2) 철회 뒤 현재 계획 유지, 재변경(v3) 확정 뒤 v1 대체됨 확인. QA 작업은 숨김 삭제했고 변경·판정 기록은 보존했다.
- 원청: 추가·수정·판정·참여자 제어 표시. 담당자: 일정 추가·수정·판정 버튼 없음, 제안 화면 접근 가능. 열람자: 제안 버튼 없음·직접 제안 URL 거부, 참여자 이메일·권한 회수 없음.
- 다른 현장 직접 URL은 찾을 수 없음 화면, 역할 부족은 권한 없음 화면. 정확한 404·403 및 다른 현장 실제 객체 ID 접근은 기존 권한·변경 회귀 테스트로 확인.
- 정상 화면에서 예상하지 않은 콘솔 오류·500 응답 없음. 권한 확인용 403·404는 의도한 응답이다.
