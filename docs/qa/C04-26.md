# C04-26 화면 QA (2026-10-17)

## 수정 범위

- 시간 필수 오류가 한쪽에만 남아도 시작·종료 입력을 위쪽 기준으로 정렬한다. 직접 입력한 축약 시각과 방향키 선택에도 작업 길이를 유지한다. 수정 시 실제 날짜 버튼에 포커스한다.
- 현장은 특정 현장 선택 시 하위 메뉴 줄 오른쪽 끝에 `···`를 표시한다. 드롭다운 위치는 유지하고 수정·삭제는 각각 모달로 연다. 조정자 외에는 현장 정보만 표시한다.
- 작업 상세 `···`는 일정 복사 → 변경 제안 → 수정 → 삭제 순서. 변경 제안은 기존 폼의 embed 화면이며 오류는 모달 안에, 저장 뒤에는 해당 변경 건으로 이동한다.
- 작업·현장 삭제는 별도 모달에서 대상을 확인하며 최초 포커스는 취소다. 개발 DB의 실제 작업·현장은 삭제하지 않았다.
- 메뉴는 활성 dialog 바로 아래에 패널을 옮긴 뒤 Popover 최상위 레이어에 연다. 모달의 머리·스크롤 영역에서 잘리지 않고 스크롤을 늘리지 않는다. Esc는 메뉴부터 닫으며 닫힌 패널은 원래 details 안으로 돌려놓는다.
- 작업 메뉴는 `···` 중심에서 48px 반경의 12시·10시·8시·6시 방향, 40px 원형 아이콘이다. 설명은 마우스 오버·키보드 포커스 때만 보이며 접근성 이름은 항상 유지한다. 반시계방향 전환 280ms, 항목 간격 40ms. 동작 줄이기 CSS를 적용했다.
- 일정 복사는 공종·시간·위치·메모·업체를 채우고 새 날짜를 고른다. 전체 화면에서는 원래 작업의 현장으로 이동해 추가 모달을 연다.
- `site_id=`를 미선택으로 처리한다. 잘못된 정수는 422, 기존 현장 권한 검사는 유지한다.
- 홈·공온 판정 점검 버튼을 같은 모양·짧은 확인 시각으로 통일했다. 빈 일정의 ‘작업을 추가할까요?’·‘미리 추가할까요?’는 해당 날짜의 추가 모달로 연결한다. 전체는 현장부터 고른다. 지수의 별도 좌우 화살표는 제거했다.
- 달력 공종 점의 외곽선 잘림, 작은 화면 작업 시간 중간 줄바꿈을 정리했다.
- 주 메뉴는 홈·작업 일정·내 현장·대화로 바꾸고 변경·내 조치는 내 정보의 ‘내 업무’에서 연다(D-084). 바닥 메뉴·가이드도 같은 구조를 설명한다.
- README를 현재 제품 설명·흐름·화면 표 중심으로 다시 구성하고 SVG 소개 이미지와 가상 시연 화면을 넣었다. 교체된 인라인 삭제·작업 버튼 줄·중복 점검 버튼 스타일과 미사용 매크로 인수를 제거했다. 추가한 캐시·의존성은 없고 성능 향상을 측정·주장하지 않는다. 작업 폴더에 남은 임시 파일은 없었다.

- 수정 전 빈 현장 선택 테스트 3건 모두 422 실패 → 수정 후 통과. 다중 현장 전체 보기·단일 현장·홈·판정 내역과 잘못된 정수 입력을 검사한다.

- 최종 `uv run python scripts/check.py`: ruff check·format·mypy 통과, **650 passed · skip 없음**, 종료 코드 0.
