# C04-34 달력 칸 업종 색 막대 (2026-10-21)

## 자동 검증
- `tests/app/features/schedules` 통과. 달력 칸 테스트: 업종 막대 이름·건수와 범례 색, 업종 4개 이상이면 많은 순 3개 + `+n건`(같은 건수는 업종 목록 순), `!` 표시. 업종 색이 16개 업종을 모두 덮고 서로 다르며 판정 색과 겹치지 않는지, 작업 점 색 = 업종 색인지.

## 브라우저 확인 (Edge, 시연 계정, 포트 8001 임시 서버)
- 시안 순서(개발자 피드백): 건수 원 + 업체 색 막대 → 공온지수 같은 도넛 → 업체 색 통일 → 업종 색 막대(구글·네이버 달력 참고) → 쨍한 색이 흉하다는 피드백으로 파스텔(옅은 바탕·진한 글자·왼쪽 선).
- 1440: 현장 38의 10월. 칸마다 업종 막대(예: 10/29 철근ㆍ콘크리트 6 · 구조물해체ㆍ비계 2 · 철강구조물 1, +1건), 오른쪽 위 `!`, 공휴일 칸은 막대를 아래로 내림. 파스텔로 다시 확인. 390: 이름 없이 색 막대와 건수. 가로 넘침 없음, 스크립트 오류 0.
- 시연 현장에 판정 기록이 없어 ‘중지 n’·‘확인 n’ 알약은 화면에서 보지 못했다(테스트로 확인한 기존 집계를 그대로 씀).
