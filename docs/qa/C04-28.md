# C04-28 메뉴 스크립트 중단 수정 (2026-10-18)

## 문제와 원인
- 개발자 Edge 화면: 작업 `···` 아이콘이 `···` 오른쪽 아래로 밀려 뜨고(위치 계산 미실행), 작업·현장 `···` 항목을 눌러도 동작하지 않음.
- 원인: `base.html`의 달력 링크 앵커 코드가 `.calcell__link`를 모두 `new URL(link.href)`로 처리했다. 작업 기간 밖 날짜는 href 없는 `<span>`이라 `Invalid URL` 오류가 나고, 같은 스크립트 아래의 메뉴·모달 코드가 실행되지 않았다. 시연 현장(38)은 기간이 달 전체를 덮어 재현되지 않았다. 개발자 계정(현장 39·45 등) 데이터에서 재현.
- 전체 보기 일정 복사: 속성 안 `&copy_id`의 `&copy`를 브라우저가 ©로 해석해 `day=...©_id=` 주소로 이동, 복사 모달이 열리지 않음.

## 수정
- `a.calcell__link[href]`만 처리. 복사 주소는 `&amp;`로 작성.
- 메뉴 등장: 회전·중심에서 퍼지는 동작 제거. 각 자리에서 12·10·8·6시 순서로 180ms, 70ms 간격.
