# C04-27 작업 메뉴 위치 수정 (2026-10-18)

## 문제
- 개발자 화면: 작업 상세 `···` 메뉴의 아이콘이 `···` 주위가 아닌 엉뚱한 곳에 뜨고 눌리지 않음.
- 원인: 모달 머리가 화면 위에 붙어 위쪽 공간(70px)이 모자라면 반지름을 줄이고 아이콘을 하나씩 화면 안으로 밀었다. 원이 찌그러져 아이콘이 `···`·서로와 겹쳤다. 1280×420, 수정 폼을 연 상태에서 재현.

## 수정
- 위쪽 공간이 모자라면 원 모양 그대로 아래쪽 호(180·135·90·45°, 반지름 58px)로 돌린다. 오른쪽 닫기 버튼과 3px 떨어진다. 위쪽 공간이 충분하면 기존 12·10·8·6시(48px) 유지.
- 설명 라벨은 각 아이콘의 `···` 바깥쪽(왼·오른·위·아래)에 띄워 옆 아이콘을 가리지 않는다.
